# NexaBox — إعادة بناء الواجهة

واجهة جديدة بالكامل لإدارة المشاريع محلياً، بتصميم تحريري دافئ يجمع خلفية ورقية فاتحة، لوناً طينياً عميقاً، وبطاقات بسيطة واضحة.

## التشغيل
- افتح `index.html` عبر خادم محلي أو استضافة HTTPS.
- لا يتطلب المشروع حساباً أو اتصالاً بخدمة سحابية.
- تحفظ المشاريع على الجهاز باستخدام IndexedDB.

## الوظائف
- إضافة المشاريع وتعديلها وحذفها.
- تحديد الإصدار والحالة والتاريخ والوصف.
- البحث في أسماء المشاريع وأوصافها.
- عرض المشاريع كبطاقات أو قائمة.
- إحصاءات تلقائية للمشاريع.

## تنبيه
البيانات محلية على نفس المتصفح والجهاز. مسح بيانات الموقع أو حذف بيانات التطبيق قد يؤدي إلى فقدانها.
