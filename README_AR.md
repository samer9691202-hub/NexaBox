# NexaBox 4.1.5

تطبيق محلي لإدارة المشاريع وحفظ المرفقات على الجهاز.

## التحديث
تحتوي بطاقة كل مشروع بعد الحفظ على زرين فقط:
- **عرض التفاصيل:** يعرض وصف المشروع وحالته وتاريخه والملفات المرفقة، مع إمكانية تنزيل المرفقات أو حذفها.
- **تعديل:** يفتح نموذج تعديل بيانات المشروع وهويته ومرفقاته.

تظل إضافة المشاريع ورفع الملفات والأيقونة أو الصورة والحفظ المحلي متاحة كما في الإصدار السابق. لا يتضمن هذا الإصدار حسابات أو Supabase أو مزامنة سحابية.

## التشغيل
افتح `index.html` عبر استضافة HTTPS أو بيئة محلية تدعم IndexedDB. البيانات محفوظة في متصفح/تطبيق الجهاز نفسه.
