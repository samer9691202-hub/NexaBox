# NexaBox 4.1.9

تطبيق محلي لإدارة المشاريع وحفظ المرفقات على الجهاز.

## تحديث 4.1.7 – الإعدادات المتقدمة
- الوضع الفاتح والداكن والتحكم بشفافية بطاقات المشاريع.
- ترتيب المشاريع بالاسم أو تاريخ الإضافة أو آخر تعديل.
- العرض الشبكي أو القائمي، مع تحديد عدد المشاريع في الصفحة والتنقل بين الصفحات.
- إظهار أو إخفاء الإصدار والحالة وتاريخ التحديث والوصف على بطاقات المشاريع.
- إعداد رمز قفل محلي (4 إلى 12 رقماً)، وتفعيل القفل عند إعادة فتح التطبيق، وإخفاء واجهة المشاريع أثناء القفل.
- خيار تأكيد إضافي قبل نقل المشاريع أو الملفات إلى سجل المحذوفات.
- إعداد اللغة (العربية/English) وتغيير اتجاه الصفحة وفق الاختيار.
- إعادة ضبط إعدادات المظهر والعرض فقط دون حذف المشاريع أو المرفقات.
- عرض رقم الإصدار ومساحة التخزين المستخدمة.
- سجل محذوفات للمشاريع والملفات يتضمن الاسم وتاريخ الحذف، مع خيار الحذف النهائي.

## ملاحظات الخصوصية
البيانات والمرفقات محفوظة محلياً باستخدام IndexedDB. رمز القفل مخزن كبصمة SHA-256 محلية، لكنه قفل واجهة وليس تشفيراً لمحتوى قاعدة البيانات؛ لا تستخدمه بديلاً عن حماية الجهاز أو تشفير الملفات الحساسة. تغيير اللغة حالياً يضبط لغة المستند واتجاهه، ولا يترجم كل النصوص الثابتة في الواجهة بعد.

## الحفاظ على المشروع
تم الإبقاء على إضافة المشاريع وتعديلها وعرض التفاصيل ورفع الملفات والأيقونات والصور وتنزيل المرفقات، دون حسابات أو Supabase أو مزامنة سحابية.

## التشغيل
افتح `index.html` عبر استضافة HTTPS أو بيئة محلية تدعم IndexedDB.

## النسخ الاحتياطي والاستيراد (4.1.8)
- من الإعدادات اختر «إنشاء نسخة احتياطية» لتنزيل ملف `.nexabox.json` يحتوي بيانات المشاريع والمرفقات.
- لاستعادة البيانات اختر «استيراد نسخة احتياطية» وحدد الملف. تتم الإضافة بالدمج فقط؛ لا يحذف الاستيراد المشاريع الموجودة ولا يستبدلها.
- عند تعارض معرّف مشروع، يُنشأ معرّف جديد للمشروع المستورد، كما تُنشأ معرّفات جديدة لمرفقاته.
- يُنصح بحفظ النسخة خارج الجهاز. النسخ الاحتياطي لا يرفع البيانات إلى خادم أو سحابة.


## دعم الصور (4.1.9)
- أصبح اختيار المرفقات يوضح ويدعم صيغ الصور الشائعة: JPG وJPEG وPNG وGIF وWEBP وBMP وSVG وAVIF وHEIC وHEIF وTIFF وICO، مع بقاء رفع أنواع الملفات الأخرى متاحاً.
- تظهر معاينة مصغرة للصور المختارة قبل حفظ المشروع، وكذلك داخل تفاصيل المشروع.
- تُحفظ الصور كملفات أصلية ضمن المرفقات، وتدخل في النسخ الاحتياطي والاستيراد مع بقية الملفات.
