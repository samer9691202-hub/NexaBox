# NexaBox 3.0 — Atelier

تطبيق محلي لإدارة المشاريع بواجهة جديدة كلياً.

## التشغيل
افتح `index.html` في متصفح حديث أو ارفع محتويات الحزمة إلى استضافة صفحات ثابتة. يدعم التخزين المحلي عبر IndexedDB.

## الوظائف المتاحة
- إضافة المشاريع وتعديلها وحذفها.
- البحث بالاسم والوصف.
- عرض عدد المشاريع وحالاتها.
- التبديل بين عرض البطاقات والقائمة.
- حفظ البيانات محلياً على الجهاز.

## الخصوصية والحدود
هذه النسخة محلية فقط. لا تحتوي على إنشاء حساب أو تسجيل دخول أو Supabase أو مزامنة سحابية أو رفع/استعادة ملفات المشاريع إلى السحابة. حذف بيانات المتصفح قد يؤدي إلى فقدان البيانات المحلية.
